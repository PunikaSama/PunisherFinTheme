PunisherFinTheme

Überträgt das PunisherFin-Design auf ausgewählte Bereiche von Jellyfin Web. Header, Hero-Bereich und PunisherBanna bleiben unverändert.

Wird für Fokusrahmen, Fortschritt und primäre Aktionen verwendet.
